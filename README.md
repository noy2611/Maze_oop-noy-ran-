# Maze Game Project

This project focuses on generating and solving two-dimensional mazes through various algorithms. Users interact via a Command Line Interface (CLI), where they can create, solve, save, and load mazes. The project is built following Object-Oriented Programming (OOP) principles and is designed to be modular and efficient.

## Features

- **Maze Generation**: Users can generate mazes randomly or based on predefined rules.
- **Maze Solving**: Algorithms such as BFS (Breadth-First Search) and A* are used to solve mazes.
- **CLI Interaction**: The game operates via text-based commands entered by the user.
- **Saving and Loading**: Users can save mazes and solutions to files and load them for later use.
- **Caching**: Solutions are cached to avoid recalculating the same maze solution.

## Getting Started

### Installation

1. **Clone the repository**:
    ```bash
    git clone https://github.com/noy2611/Maze_oop-noy-ran-
    ```
    
2. **Navigate to the project directory**:
    ```bash
    cd Maze_oop-noy-ran-
    ```

### Compiling and Running in C++

1. **Compile the project**:
    If you are using `g++` as your compiler, run:
    ```bash
    g++ -o maze_game main.cpp maze.cpp
    ```

2. **Run the executable**:
    ```bash
    ./maze_game
    ```
